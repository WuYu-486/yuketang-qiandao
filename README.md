# 雨课堂助手（自动签到 + 自动答题）

带图形界面的雨课堂自动化小工具：自动等课、自动签到进课堂、实时监听题目并自动作答，支持多账号同时挂机。

> 核心逻辑整理自 [timeflykai/lazytool](https://github.com/timeflykai/lazytool)，感谢原作者的分享。仅供个人学习与研究使用，请遵守所在学校的规定，使用风险自负。

## 功能一览

- **自动等课 + 签到**：每 30 秒检测一次是否有课，检测到就自动签到进课堂；失败按退避节奏持续重试，不放弃这节课。
- **自动答题**：websocket 实时监听课堂事件，题目下发后立即用大模型作答。
- **AI 答案共享**：同一堂课同一道题，多账号只调用一次 AI，其余账号复用结果（本地 SQLite 租约防重复）。
- **按账号 AI 开关**：每个账号独立控制是否允许 AI 作答，运行中切换、下一道题生效。
- **定时开关**：每个账号可单独设定开始 / 停止监听的时间，到点自动执行。
- **图形界面**：窗口内显示登录二维码，支持多账号、一键换新码、日志与历史记录。
- **掉线提示**：登录失效立刻弹出新二维码；界面显示「最近事件 X 分钟前」，长时间无输出会提示可能卡住。
- **微信推送（可选）**：配置企业微信后可把状态和二维码推到手机，默认关闭。

## 环境要求

- Windows（图形界面基于系统自带的 tkinter）
- Python 3.8+
- 依赖：`requests`、`websockets`、`pillow`
- 网络可访问 `www.yuketang.cn`

## 安装

在仓库根目录执行：

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

`py` 命令不可用时，换成你本机 Python 的完整路径即可。装好后所有命令都用 `.venv\Scripts\python.exe` 运行，不会污染本机环境。

## 使用

### 图形界面（推荐）

双击 `gui.pyw`（或 `gui.bat`），选中左侧账号 → 点「刷新登录二维码」→ 手机微信扫码 → 程序自动开始监听，有课就签到、有题就作答。

- **多账号**：左侧「添加账号」可挂多个人的号，各自扫码、各自监听，彼此独立。关闭窗口会停止所有监听。
- **AI 作答开关**：顶部「当前账号」旁的「AI 作答」勾选框，默认开启；关闭后该账号只用雨课堂下发的答案，不调用大模型，也不用共享 AI 结果。设置保存在 `accounts.json`，运行中切换下一道题生效。
- **定时开关**：左侧「定时开始监听 / 定时停止监听 / 取消定时」。填 `30` 表示 30 分钟后执行，填 `13:50` 表示到点执行（已过则顺延到明天），最小单位 1 分钟。定时写入 `accounts.json`，重开界面仍有效；界面需保持开启，到点才会执行。停止只影响该账号。

> 双击 `gui.bat` 若弹出「无法验证发布者」，是 Windows 对批处理文件的安全提示，不是程序问题；改双击 `gui.pyw` 即可（用 pythonw 启动，效果一样，不弹提示）。

### 命令行

| 命令 | 说明 |
| --- | --- |
| `run.bat` | 打开交互菜单 |
| `run.py check` | 环境自检：依赖 + 雨课堂连通性 |
| `run.py login` | 强制扫码登录，换一张新二维码 |
| `run.py status` | 查看登录状态、当前有没有课 |
| `run.py ykt` | 开始监听：等课 → 签到 → 自动作答 |

以上命令都支持 `--name 账号标识`，不同 `name` 使用互相独立的 `cookie_名称`、`qrcode_名称.jpg`。

## 自动答题说明

题目下发后立即作答：把题干、选项和所在课件的整页图一起发给大模型，拿到答案再提交。

**答案生成**

- 提示词限定只返回选项标识，并开启接口 JSON 模式；模型返回的各种写法（`B`、`（B）`、`B.`、选项文字、多选连写 `BC` 等）提交前统一规整成选项 key。
- 题干或选项带图片时随题发给多模态模型（最多 3 张）；模型不支持图片则自动退回纯文字。图片下载有总时长预算，慢图不会拖垮整道题。
- DeepSeek 默认 `high` 推理强度保证准确率，单次请求设总时长上限、网络超时自动重试一次；题目有作答时限时按剩余时间自动收紧超时。
- 换模型、指定 API Key、关闭图片等见 [CONFIG.md](CONFIG.md)。

**时限与重试**

- 题目带时限（`limit`）时记录截止时间，死线按 `sendTime + limit + 30 秒` 计算（预留老师临时延长的缓冲）；到点后不再新发起 AI 调用，已发出的请求最多再收尾 30 秒。课程结束时取消未开始的任务。
- 收到老师端 `extendtime` 事件会更新死线，并立即重发还没提交成功的答案。
- 提交遇到题目关闭（`LESSON_PROBLEM_FINISHED`）自动重试 2 次、间隔 5 秒；收到延长事件会提前叫醒重试。答案先缓存，重新开放后直接重发，不重复问模型。
- 拿不到可用答案时记「跳过作答」，原始数据存为 `debug_problem_*.json`，不提交空答案。

**跨账号共享**

- 同一堂课同一道题默认只由一个账号调用 AI，其他账号从本地 SQLite 缓存取结果后各自提交；按 `lessonId + problemId + 题目指纹` 识别，无需配置班级。
- 抢到计算权的进程持租约并续期，其他进程只等待，不会重复调用。缓存默认保留 24 小时，文件不提交到 git。
- 关闭了「AI 作答」的账号不参与共享，只用雨课堂下发的答案。

## 配置

`config.json` 首次运行时自动生成，模板见 `config.example.json`；全部字段（账号名、签到方式、大模型、企业微信推送等）见 [CONFIG.md](CONFIG.md)。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 二维码扫不了 / 提示过期 | 一张码约 2 分钟失效，点「刷新登录二维码」换新；程序也会自动换新 |
| 签到失败会一直重试吗 | 会。首次失败后 10 秒重试，每失败 6 次间隔加 30 秒，最长 310 秒，次数不限；签到成功、课程结束或停止监听后重置为 10 秒 |
| 界面报「没找到 .venv」 | 还没装依赖，按「安装」一节建好虚拟环境 |
| 双击 gui.bat 没反应 | 手动跑 `.venv\Scripts\python.exe gui.py` 看报错；启动失败时根目录会留下 `gui_error.log` |
| 双击 gui.bat 弹「无法验证发布者」 | Windows 对批处理的安全提示，改双击 `gui.pyw`，或在终端里运行 `gui.bat` |
| 窗口只有文字没有二维码 | 没装 pillow：`.venv\Scripts\python.exe -m pip install pillow` |
| 能帮别人挂账号吗 | 可以。每个账号单独添加、各自扫码、各自「开始监听」；别关窗口 |

## 已知限制

- 不配置大模型 API Key 时，课内题会跳过作答。
- 依赖雨课堂接口与 websocket 协议，对方一旦调整就可能失效。
- 图形界面只在 Windows 桌面环境验证过。

`cookie_账号`、`qrcode_账号.jpg`、`config.json`、`dashscope_key.txt` 等本地文件包含隐私，已在 `.gitignore` 中排除，不要外传或提交；日志、历史记录、账号列表等运行产物同样只在本地生成。
