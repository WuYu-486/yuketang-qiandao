# 雨课堂助手（自动签到 + 自动答题）

带图形界面的雨课堂自动化小工具：自动等课、自动签到进课堂、实时监听题目并自动作答，支持多账号同时挂机。

> 核心逻辑整理自 [timeflykai/lazytool](https://github.com/timeflykai/lazytool) 的雨课堂部分。仅供个人学习与研究使用，请遵守所在学校的规定，使用风险自负。

## 功能

- **自动等课**：每 30 秒查一次有没有课正在进行，检测到就自动签到进课堂；签到失败会按退避节奏一直重试，不会直接放弃这节课。
- **定时开关**：给每个账号定好开始 / 停止监听的时间（如 20:30 开始、22:30 停止），到点自动执行，多账号各算各的。
- **自动答题**：websocket 实时监听课堂事件，题目下发后立即开始作答；答案用大模型生成。
- **AI 答案共享**：同一堂课、同一道题多个账号只调用一次 AI，其他账号等待并复用结果；本地 SQLite 租约保证不会重复调用。
- **按账号 AI 开关**：每个账号单独勾选是否允许 AI 作答；关闭后只使用雨课堂下发的答案，拿不到就跳过。运行中切换，下一道题生效，不需要停掉重开。
- **图形界面**：二维码直接显示在窗口里，支持多账号、一键强制换新码、日志与历史记录。
- **掉线看得见**：登录失效会立刻提示并自动弹出新二维码；等课与跟课都有心跳，界面显示「最近事件 X 分钟前」，长时间没有输出会提示可能卡住。
- **可选的微信推送**：配置企业微信后可以把状态和二维码推到手机（默认关闭）。

## 环境要求

- 系统：Windows（图形界面基于系统自带的 tkinter）
- Python：3.8 及以上
- 依赖：`requests`、`websockets`、`pillow`
- 网络：能访问 `www.yuketang.cn`

## 安装

在仓库根目录执行：

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

`py` 命令不可用时，换成你本机 Python 的完整路径即可。装好后所有命令都用 `.venv\Scripts\python.exe` 运行，不会污染本机环境。

## 使用

**图形界面（推荐）**：双击 `gui.pyw`（或 `gui.bat`），选中左侧账号 → 点「刷新登录二维码」→ 手机微信扫码 → 程序自动开始监听，有课就签到、有题就作答。左侧可「添加账号」挂多个人的号，各账号彼此独立。

> 双击 `gui.bat` 如果弹出「无法验证发布者」的安全警告，是 Windows 对批处理文件的提示，不是程序本身的问题；双击 `gui.pyw` 不会弹这个提示。`gui.pyw` 用 pythonw 启动，和 `gui.bat` 效果一样。

左侧还有「定时开始监听 / 定时停止监听 / 取消定时」：给选中账号定个时间——填 `30` 表示 30 分钟后开始或停止，填 `13:50` 表示到点开始或停止（已经过了就顺延到明天），到点自动开始或停止监听。停止只影响这一个账号，其他账号照常。每个账号各算各的，最小单位 1 分钟，定时会写进 `accounts.json`，重开界面也还在；界面要一直开着，到点才会执行。

**命令行**：

| 命令 | 说明 |
| --- | --- |
| `run.bat` | 打开交互菜单 |
| `run.py check` | 环境自检：依赖 + 雨课堂连通性 |
| `run.py login` | 强制扫码登录，换一张新二维码 |
| `run.py status` | 查看登录状态、当前有没有课 |
| `run.py ykt` | 开始监听：等课 → 签到 → 自动作答 |

以上命令都支持 `--name 账号标识`，不同 `name` 使用互相独立的 `cookie_名称`、`qrcode_名称.jpg`。

## 自动答题

课内题交给大模型作答：题目下发后立即开始，把题干、选项和这道题所在课件的整页图一起发给模型，拿到答案再提交。

- 提示词里写死了输出格式，只允许返回选项标识，并开启接口的 JSON 模式，模型不能加解释、句号或括号。
- 题干或选项里带图片时，图片会一起发给多模态模型（最多 3 张）；模型不支持图片就自动退回纯文字，不会因为图片丢掉整道题。图片下载有总时长预算，慢图不会把整道题拖到超时。
- DeepSeek 默认用 `high` 推理强度保证准确率，同时给单次请求设总时长上限、网络超时自动重试一次：`high` 遇到复杂图片题时可能生成几千个推理 token、单次要一分钟以上，所以超时留得比较宽；题目本身有作答时限时会按剩余时间自动收紧。
- 模型给的答案写法五花八门（`B`、`（B）`、`B.`、直接抄选项文字、多选连写 `BC` 等），提交前都会统一规整成选项 key。
- 题目带作答时限（`limit`）时，程序会记录截止时间：到点后不再调用大模型，课程结束时也会取消还没开始作答的任务，避免答题时间结束后继续浪费 token。老师偶尔会临时延长答题时间，所以死线按 `sendTime + limit + 30 秒` 计算，多留 30 秒缓冲；题目没有时限时不受影响。收到老师端的 `extendtime` 事件会更新死线，并立即重发还没提交成功的答案。
- 提交答案时如果刚好遇到题目关闭（`LESSON_PROBLEM_FINISHED`），会自动重试 2 次，每次间隔 5 秒；收到延长事件会提前叫醒重试，不用等满 5 秒。答案会先缓存，重新开放后直接重发，不会重复问模型。已经发出的 AI 请求在死线后最多再收尾 30 秒，但死线后不会新发起 AI 调用。
- 拿不到可用答案时，这道题记「跳过作答」，并把题目原始数据存成 `debug_problem_*.json`，不会提交空答案。
- 同一堂课、同一道题的 AI 答案默认跨账号共享：只会有一个账号真正调用模型，其他账号从本地 SQLite 缓存取结果，再各自提交。用 `lessonId + problemId + 题目指纹` 自动识别，不需要配置班级；抢到计算权的进程持租约并续期，其他进程只等待，不会重复调用 AI。共享缓存默认保留 24 小时，文件不会提交到 git。
- 每个账号在顶部「当前账号」旁有独立的「AI 作答」开关，默认开启；关闭后该账号只使用雨课堂下发的答案，不再调用大模型，也不使用共享 AI 结果。开关保存在 `accounts.json` 的 `ai_answer` 里，多账号互不影响。
- 想换模型、指定 API Key 或关掉图片，见 [CONFIG.md](CONFIG.md)。

## 配置

`config.json` 首次运行时自动生成，模板见 `config.example.json`；全部字段（账号名、签到方式、大模型、企业微信推送等）见 [CONFIG.md](CONFIG.md)。

## 常见问题

- **二维码扫不了或提示过期**：一张二维码约 2 分钟失效，点「刷新登录二维码」换一张，程序自身也会自动换新。
- **签到失败会一直重试吗**：会。第一次失败后等 10 秒重试；之后每失败 6 次把间隔加 30 秒，最长 310 秒；重试次数不限。签到成功、课程结束或停止监听后，计数重新从 10 秒开始。
- **界面报「没找到 .venv」**：还没装依赖，按上面的「安装」一节建好虚拟环境即可。
- **双击 gui.bat 没反应**：手动跑 `.venv\Scripts\python.exe gui.py` 看报错；启动失败时根目录会留下 `gui_error.log`。
- **双击 gui.bat 弹出「无法验证发布者」**：这是 Windows 对批处理文件的安全提示（目录被标成低完整性或来自网络时常见），不是程序问题。改双击 `gui.pyw` 即可；如果只想用命令行，也可以在终端里运行 `gui.bat`，不会弹这个提示。
- **窗口里只有文字没有二维码**：没装 pillow，执行 `.venv\Scripts\python.exe -m pip install pillow` 即可。
- **能帮别人挂账号吗**：可以。每个账号单独添加、各自扫码一次，然后各自点「开始监听」；别关窗口，关窗口会一并停止所有监听。

## 已知限制

- 不配置大模型 API Key 时，课内题会跳过作答。
- 依赖雨课堂接口与 websocket 协议，对方一旦调整就可能失效。
- 图形界面只在 Windows 桌面环境验证过。

## 注意

`cookie_账号`、`qrcode_账号.jpg`、`config.json`、`dashscope_key.txt` 等本地文件包含隐私，已在 `.gitignore` 中排除，不要外传或提交；日志、历史记录、账号列表等运行产物同样只在本地生成。
