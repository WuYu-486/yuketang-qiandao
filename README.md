# 雨课堂助手（自动签到 + 自动答题）

带图形界面的雨课堂自动化小工具：自动等课、自动签到进课堂、实时监听题目并自动作答，支持多账号同时挂机。

> 核心逻辑整理自 [timeflykai/lazytool](https://github.com/timeflykai/lazytool)，感谢原作者的分享。仅供个人学习与研究使用，请遵守所在学校的规定，使用风险自负。

## 功能

- **自动等课 + 签到**：每 30 秒检测一次是否有课，检测到就自动签到；失败按退避节奏持续重试。
- **自动答题**：websocket 实时监听课堂事件，题目下发后立即用大模型作答，[机制详解](docs/auto-answer.md)。
- **AI 答案共享**：同一堂课同一道题，多账号只调用一次 AI，其余账号复用结果。
- **多账号 + 定时**：各账号独立扫码、监听、AI 开关，可单独定时开始 / 停止。
- **图形界面**：窗口内显示登录二维码，掉线自动弹新码，带日志与历史记录。
- **微信推送（可选）**：配置企业微信后可把状态和二维码推到手机，默认关闭。

## 快速开始

环境：Windows、Python 3.8+、可访问 `www.yuketang.cn`。

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

然后双击 `gui.pyw`，选中账号 → 刷新登录二维码 → 微信扫码，程序即自动开始监听。多账号、定时、命令行用法见[使用说明](docs/usage.md)。
