# 使用说明

## 图形界面（推荐）

双击 `gui.pyw`（或 `gui.bat`），选中左侧账号 → 点「刷新登录二维码」→ 手机微信扫码 → 程序自动开始监听，有课就签到、有题就作答。

> 双击 `gui.bat` 若弹出「无法验证发布者」，是 Windows 对批处理文件的安全提示，不是程序问题；改双击 `gui.pyw` 即可（用 pythonw 启动，效果一样，不弹提示）。

### 多账号

左侧「添加账号」可挂多个人的号，各自扫码、各自监听，彼此独立。关闭窗口会停止所有监听。

### AI 作答开关

顶部「当前账号」旁的「AI 作答」勾选框，默认开启；关闭后该账号只用雨课堂下发的答案，不调用大模型，也不用共享 AI 结果。设置保存在 `accounts.json`，运行中切换下一道题生效。

### 定时开关

左侧「定时开始监听 / 定时停止监听 / 取消定时」：

- 填 `30` 表示 30 分钟后执行；填 `13:50` 表示到点执行（已过则顺延到明天），最小单位 1 分钟。
- 定时写入 `accounts.json`，重开界面仍有效；界面需保持开启，到点才会执行。
- 停止只影响该账号，其他账号照常。

## 命令行

| 命令 | 说明 |
| --- | --- |
| `run.bat` | 打开交互菜单 |
| `run.py check` | 环境自检：依赖 + 雨课堂连通性 |
| `run.py login` | 强制扫码登录，换一张新二维码 |
| `run.py status` | 查看登录状态、当前有没有课 |
| `run.py ykt` | 开始监听：等课 → 签到 → 自动作答 |

以上命令都支持 `--name 账号标识`，不同 `name` 使用互相独立的 `cookie_名称`、`qrcode_名称.jpg`。
