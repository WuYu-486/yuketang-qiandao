# 自动答题机制

题目下发后立即作答：把题干、选项和所在课件的整页图一起发给大模型，拿到答案再提交。模型、API Key 等配置见 [CONFIG.md](../CONFIG.md)。

## 答案生成

- 提示词限定只返回选项标识，并开启接口 JSON 模式；模型返回的各种写法（`B`、`（B）`、`B.`、选项文字、多选连写 `BC` 等）提交前统一规整成选项 key。
- 题干或选项带图片时随题发给多模态模型（最多 3 张）；模型不支持图片则自动退回纯文字。图片下载有总时长预算，慢图不会拖垮整道题。
- DeepSeek 默认 `high` 推理强度保证准确率，单次请求设总时长上限、网络超时自动重试一次；题目有作答时限时按剩余时间自动收紧超时。

## 时限与重试

- 题目带时限（`limit`）时记录截止时间，死线按 `sendTime + limit + 30 秒` 计算（预留老师临时延长的缓冲）；到点后不再新发起 AI 调用，已发出的请求最多再收尾 30 秒。课程结束时取消未开始的任务。
- 收到老师端 `extendtime` 事件会更新死线，并立即重发还没提交成功的答案。
- 提交遇到题目关闭（`LESSON_PROBLEM_FINISHED`）自动重试 2 次、间隔 5 秒；收到延长事件会提前叫醒重试。答案先缓存，重新开放后直接重发，不重复问模型。
- 拿不到可用答案时记「跳过作答」，原始数据存为 `debug_problem_*.json`，不提交空答案。

## 跨账号共享

- 同一堂课同一道题默认只由一个账号调用 AI，其他账号从本地 SQLite 缓存取结果后各自提交；按 `lessonId + problemId + 题目指纹` 识别，无需配置班级。
- 抢到计算权的进程持租约并续期，其他进程只等待，不会重复调用。缓存默认保留 24 小时，文件不提交到 git。
- 关闭了「AI 作答」的账号不参与共享，只用雨课堂下发的答案。
